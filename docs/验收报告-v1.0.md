## 外部条件限制

以下项目代码和 UI 已实现，但本次无法在不接管用户账号/工具安装的前提下完成真实外部验证：

- 知识库真实同步与“待测试/负责人”更新：当前知识库只能使用已登录网页会话，需要用户在登录窗口中完成账号登录或会话检查。
- Cursor 真实执行：本机未检测到 `cursor-agent`，因此只能验证 provider 选择、命令编排和不可用提示，不能伪造 Cursor 成功结果。
- 真实远程 push：为避免触碰用户仓库，本次只验证临时仓库的 commit、脏工作区阻止和冲突阻断；没有向真实远程推送。

这些不是本地实现失败，而是缺少真实登录会话、Cursor 可执行程序或测试远程仓库。接入条件满足后，建议按同一验收清单补跑三项外部验证。
