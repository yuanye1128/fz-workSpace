## 外部条件限制

以下项目代码和 UI 已实现，但完整外部验证仍依赖用户环境：

- 知识库真实同步与“待测试/负责人”更新：需要已登录网页会话。
- 完成工作量统计：需要已登录知识库，并访问个人活动页与工单详情。
- 真实 AI 工具执行：需本机已安装并登录 Cursor / Codex / Claude Code。
- 真实远程 push：建议使用测试仓库验证 squash 合回与冲突路径。
